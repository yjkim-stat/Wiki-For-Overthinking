# Solved

Where a document from [`../issues/`](../issues/) goes once the thing it
describes has been dealt with, with a **Resolution** section appended: which
option was taken, what the document left open, and how somebody would see for
themselves.

Nothing is deleted and the original text is not edited to match the outcome —
a document rewritten after the fact stops being evidence of what was actually
believed at the time, which is most of what makes the record worth keeping.
