세 갈래가 확정한 것

두 질문 — 종료 여부, 추가 토큰의 marginal utility 부호 — 이 만드는 배타적 세 경우.
갈래확정된 것확정되지 않은 것
① 포화
종료 · 이득 ≈ 0		 Gemini·GPT-5·O-시리즈 모두 예산을 올려도 평평하고, 12K 이후로는 내려간다. 하락은 잡음이 아니다 (95% CI [−1.4, −0.4]) 꺾이는 지점이 문제마다 다르다 — 사전 판별 방법 부재
② 역효과
종료 · 이득 < 0		 미끼가 섞이면 토큰이 늘수록 정확도가 내려간다. agent에서는 내부 추론이 행동을 밀어내며 해결률 하락 어떤 과제가 역전을 일으키는지 사전에 판별할 규칙이 없다. 에이전트 근거는 한 편이고 지표는 LLM judge

Task design 단계의 기준선 확정

목적은 쉬운 문항 수집이 아님. 필요량을 task design에 고정 → 갈래 ②가 re-run으로 얻는 기준선을 평가 전에 확보.
필요량 확정 · 실측형 — OptimalThinkingBench
별도 모델의 k = 8 샘플이 전부 기준 답과 일치할 때만 채택. 원문: “100% 일치 요구가 긴 추론이 필요 없을 만큼 쉬운 문제임을 보장한다.” → 해당 문항의 필요량 = 생각 토큰 0.
필요량 확정 · 계산형 — LLMThinkBench
14개 과제 전부 f : X → Y 결정적 함수
복잡도 O(n), O(n log n), O(n²) 기지 → 실측 없이 필요 작업량의 상한이 수학적으로 확정.
대가 · 필요량 산출 가능한 과제에 한정 → 쉬운 쪽 편중. OptimalThinkingBench는 난이도 높은 UnderthinkingBench를 짝지어 편향 상쇄, LLMThinkBench는 미상쇄.
잔여 문제 · 필요량 확인 주체가 평가 대상이 아닌 별도 모델 — 주장 가능 범위는 “이 문항은 긴 추론 불요”까지, “이 모델이 짧게 해결 가능”은 아님.

AUC의 출처 — 분류기 지표

고양이 사진 5장 분류기. 출력은 확률, 양성 판정 threshold는 별개의 선택.
Threshold 1개 = 곡선 위의 점 1개. AUC는 그 점을 고르지 않고 분류기를 요약하기 위한 지표.
5장 예시는 ROC-AUC 정의 설명을 위한 본 발표의 창작. 넓이 0.833과 순위 해석 5/6의 일치는 ROC-AUC의 기지 성질.
