# class imbalance

<!-- auto:begin -->

When one label dominates an evaluation set, so that accuracy stops being informative and a metric can be satisfied by a degenerate rule. All three sources here treat it as something to design around rather than to report. The Parkinson's screen has 13 percent prevalence, at which predicting all-healthy already scores 0.87, so it reports AUROC, F1 and negative predictive value at a Youden-optimal operating point instead, and reads its own result as a rule-out triage screen (NPV 0.95) rather than as a diagnostic (PPV 0.35). The theory-of-mind benchmark takes the opposite approach and removes the problem by construction, balancing the set at roughly 50 percent TRUE per ability precisely so that a residual TRUE/FALSE prior shows up as a gap between accuracy and macro-F1 -- and its steering result is then read through class-conditional recall, where a model moves from a degenerate 10.7/98.0 to a balanced 73.8/80.2, a change accuracy alone would have attributed to competence rather than to threshold. The robot-plan verification work shows what happens without either precaution: with reject holding 31 of 38 cases, the authors state that per-class precision and recall are not stable and substitute aggregate deployment-aligned metrics. Together the sources make one point: the imbalance determines which metric can be read at all, and choosing it afterwards is choosing the conclusion.
