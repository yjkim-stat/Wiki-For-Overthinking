# reinforcement learning with verifiable rewards

<!-- auto:begin -->

Training against an automatically checkable outcome signal — a correct final answer, a passing test — rather than a learned reward model, which removes reward-model gaming as a failure mode and restricts the method to domains where correctness can be checked. The archive's anchor source uses it to elicit long chain-of-thought reasoning without supervised reasoning traces. The second shows the recipe travelling outside reasoning entirely, using RLVR to train an attack planner against cyber defences, with over 13,000 interaction trajectories collected for the purpose. The gap between those two uses is a fair picture of the term's current breadth: a specific training signal that is being applied wherever an automatic checker exists.

## Appears in

- [DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning](../../archive/papers/2025/arxiv-2501-12948/summary.md) — Shows that reasoning ability can be incentivized in an LLM by pure reinforcement learning on verifiable tasks, with no human-annotated reasoning trajectories, and that the resulting reasoning patterns can be transferred to smaller models.
- [Trident : How to Break Deep Reinforcement Learning Cyber Defenses (Agentic)](../../archive/papers/2026/arxiv-2608-04317/summary.md) — An agentic RLVR red-teaming framework that trains an LLM planner to attack deep-RL cyber-defence agents, showing those defences were only ever evaluated against static attackers.
