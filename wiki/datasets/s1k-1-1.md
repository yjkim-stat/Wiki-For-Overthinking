# s1k-1.1

<!-- auto:begin -->

Neither source describes s1K-1.1 directly; it appears as a named reference dataset in their reasoning-compression work. A*-Thought selects a short, high-information subset of a long reasoning trace via A* search over reasoning spans as SFT data; SuCo instead trains on the shortest reasoning prefix at which model confidence crosses a difficulty-adaptive threshold (its 'Minimal Sufficient CoT'), combined with a GRPO stage penalising both over- and under-thinking. Neither states how s1K-1.1 itself was built or used.

- [SelfBudgeter: Adaptive Token Allocation for Efficient LLM Reasoning](../../archive/papers/2026/doi-10-18653-v1-2026-findings-acl-1063/summary.md) — SelfBudgeter trains a reasoning model to emit its own predicted token budget before answering (<budget>N</budget><solution>...</solution>) via a cold-start plus budget-guided GRPO pipeline, cutting response length ~61% on math benchmarks while preserving or improving accuracy, and letting users see the estimated wait time or pre-fill a hard budget upfront.
