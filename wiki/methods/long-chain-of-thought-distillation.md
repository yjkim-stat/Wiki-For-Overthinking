# long chain-of-thought distillation

<!-- auto:begin -->

Supervised finetuning on long reasoning traces generated by a stronger reasoning model, used by both sources as the initialization a later stage builds on rather than as the contribution. One uses it as the cold start that activates an explicit translation process before reinforcement learning aligns that process with the final output. The other makes it the *control arm*, which is the more interesting use: distilling and RLVR-training the same base checkpoint on the same data isolates what reinforcement learning changes, and the answer is that the RL policy is more decided at semantic branch points while the distilled one explores more — with the flatter distilled policy outperforming it by about 60% once invalid continuations are masked out. So the technique is both a standard starting point and, when both arms are trained by the same hands, the cleanest available comparison for what RL adds.
